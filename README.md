# Basalt (working name): a managed service for ClickHouse®

Open-source, self-hostable platform that lets tenants request ClickHouse clusters through an API and connect with standard ClickHouse clients.

**Status: Phase 0 (design), awaiting approval. There is no implementation yet.**
